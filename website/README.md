# ThermoVerse website prototype

English-first, zero-dependency static prototype covering Home, Technology (LATCHES), Use Cases & Services, About Us (including FACES Workforce Program), and Contact Us.

Run locally from this directory:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/`. The contact form is intentionally a preview: it does not send data, write to local storage, or pretend to create a CRM record. CTA links prefill the inquiry type and source page so the eventual backend contract is visible.

Content uses conservative, unverified language. No performance, safety, compliance, company-history, partner, team, or carbon-credit claims are presented as facts. CRM, privacy policy, recipient email, and approved technical copy remain to be confirmed by ThermoVerse.
